# ANN-Battery-Aging-Prediction-EV

## Project Overview
This project uses **Artificial Neural Networks (ANN)** to predict battery aging in Electric Vehicles (EVs). It also explores sustainable hydrometallurgical recycling methods for end-of-life EV batteries.

## Project Workflow
| Step | Description |
|------|-------------|
| 1 | Data Collection |
| 2 | Data Preprocessing |
| 3 | Correlation Heatmap Analysis |
| 4 | Principal Component Analysis (PCA) |
| 5 | Feature Selection |
| 6 | Data Split (Train/Test) |
| 7 | Hyperparameter Tuning |
| 8 | ANN Training |
| 9 | Evaluation Metrics |
| 10 | State of Health (SOH) Conversion |

- Neural Network Toolbox
- Statistics and Machine Learning Toolbox
